## Engineering themes I practise

### SDE & core computer science

- Data structures and algorithms; time and space complexity.
- Object-oriented programming, modularity, separation of concerns, and reusable components.
- SQL, relational modelling, indexes/constraints, transaction boundaries, and schema migrations.
- HTTP, REST conventions, request/response validation, error handling, and API contracts.

### Backend engineering & system design

- Distributed systems architecture: Base62 URL shortener with Single-Flight cache stampede mitigation, 5-algorithm rate limiter with hot-key sharding, multi-node WebSocket chat scaling via Redis Pub/Sub backplane, hybrid fan-out social news feed with cursor pagination, and high-concurrency ticket booking engine with OCC CAS versioning and Saga compensation.
- Application factories, blueprints/routers, layered services, and multi-role applications.
- Authentication and authorization: JWT, sessions, role-based access control, and tenant-aware access patterns.
- Cache-aside patterns, cache invalidation, background task queues, scheduled jobs, and asynchronous exports.
- Concurrency and correctness: idempotency, duplicate-booking prevention, database transactions, retry-safe processing, and durable local storage.
- Reliability concepts: bounded resource use, timeouts, retries, graceful fallbacks, health/readiness endpoints, structured logging, and failure testing.
- System design practice includes API boundaries, data flow, bottlenecks, state ownership, consistency, and scaling trade-offs.

### ML, deep learning & data science

- Supervised learning, text classification, feature engineering, classical model ensembles, and hyperparameter tuning.
- TF-IDF word/character n-grams, class imbalance handling, cross-validation, Macro F1, MAP@3, confusion matrices, and ROC analysis.
- Transformer representations, sentence embeddings, NER, semantic matching, reranking, and model comparisons.
- Neural architectures explored include MLPs, BiLSTMs, attention pooling, autoencoders, CNN-LSTM, and reinforcement-learning approaches.

### GenAI & MLOps

- Retrieval-augmented generation with dense and lexical retrieval, reciprocal-rank fusion, cross-encoder reranking, and grounded response workflows.
- LangChain/LangGraph agent orchestration, structured model outputs, prompt design, and provider abstraction/fallbacks.
- Experiment tracking with Weights & Biases; repeatable training and evaluation notebooks; simple REST model serving; containerisation and deployment.
- Interested in deeper work on evaluation datasets, offline/online metrics, data/model versioning, observability, and reliable production ML systems.
